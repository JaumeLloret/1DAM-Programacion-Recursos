# 1DAM · Programación · Recursos públicos

Biblioteca estable de recursos de alumnado para **Programación de 1.º DAM semipresencial**.

## Qué es este repositorio

- **AULES es el curso**: teoría, secuencia, tareas, evaluación, feedback y recuperación.
- **Este repositorio es la biblioteca pública**: código de ejemplo, starters seguros,
  datos y ficheros de trabajo enlazados desde AULES.
- El repositorio se publica completo P1–P9 para que los enlaces del curso sean
  permanentes y reutilizables en cursos futuros.
- No contiene soluciones, oráculos, material docente, datos personales ni REC.
- No adelanta código o arquitectura AulaFlow reservados para hitos posteriores.

Antes de que Entornos imparta Git/GitHub, puedes usar este repositorio simplemente
como una web para consultar ficheros. AULES mantiene además los ZIP descargables.
