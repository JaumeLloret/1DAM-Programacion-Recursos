# 1DAM · Programación · Recursos

Repositorio público de recursos de alumnado para **Programación de 1.º DAM semipresencial**.

## Qué encontrarás aquí

Código Java, datos, ejemplos reproducibles y starters que acompañan a P1–P9.

**AULES sigue siendo el curso:** teoría, orden de estudio, tareas, evaluación, recuperación y entregas se gestionan allí. Este repositorio es una biblioteca estable para consultar archivos concretos y conservar enlaces duraderos entre cursos académicos.

## Uso

Puedes navegar y descargar archivos desde la web de GitHub. El uso formal de Git/GitHub se introduce en **Entornos de Desarrollo** cuando corresponde; este repositorio no adelanta esa enseñanza.

## Política de publicación

Este repositorio contiene solo material destinado al alumnado. Se excluyen:

- soluciones y oráculos docentes;
- recuperaciones y pruebas ocultas;
- datos personales, credenciales y secretos;
- material interno de evaluación;
- arquitectura o código de AulaFlow que no deba revelarse todavía.

Los recursos específicos de AulaFlow se distribuyen desde AULES en el nivel curricular correspondiente.

## Curso

Preparado para el curso 2026/27 y pensado como biblioteca estable para cursos posteriores, con mejoras versionadas cuando sea necesario.
