# Starter P3

Proyecto mínimo para JDK 26. Antes de usarlo, completa la ficha humana del laboratorio. El starter compila, pero sus métodos pendientes devuelven valores provisionales y **no son una solución**.

```text
mvn -q clean compile
mvn -q exec:java -Dexec.mainClass=es.ies.p3.starter.Main
```

Si el plugin `exec` no está disponible, ejecuta `Main` desde IntelliJ. No cambies `maven.compiler.release` para ocultar un JDK incorrecto.
