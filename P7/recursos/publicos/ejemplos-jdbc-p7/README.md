# Ejemplos JDBC P7

Requieren JDK 26 y Maven. Ejecuta cada `main` desde IntelliJ o compila con `mvn package`. Las bases se crean bajo `target/`; no las versiones.

- `DemoConexionSQLite`: conexión, versión y reapertura.
- `DemoPreparedStatement`: parámetros y lectura.
- `DemoRollback`: fallo en segunda operación y estado restaurado.

Son microejemplos de lectura; no constituyen la solución de AulaFlow ni acreditan CE.
